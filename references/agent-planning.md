# Agent读图与布局规划

本参考指导Agent做工程图面判断，不要求工具自动复现全部视觉理解。Agent在本次授权内自行选区、分组、调整位置；常规布局选择不逐项请用户确认。目标身份、内容保护和执行安全门槛不放宽。

## 先读内框，再确定可用范围

1. 从已绑定图读取内框候选的原生范围、图层/类型/句柄并看全幅图面。内框可能是代理图形或图块；优先尝试底座已有通用属性/范围能力。代理范围若可读，也可能覆盖外框、图签、多个矩形或整组内容；Agent依据连续矩形、相邻图幅、道路分段与图签关系识别本幅内框，不把一个矩形包围盒自动当内框。
2. 当前工具不返回代理有效范围、范围过大或包含多个框时，说明缺口，结合可见图面定位；可用时读一个代表性布局视口反算模型范围。换算须处理模型/纸空间、单位、比例、中心和旋转；工具未支持则按已有证据估计，不能把屏幕像素或纸空间毫米直接用作模型坐标。不为此默认安装代理解码器、爆炸对象或改底图。
3. 同类等比例分幅复用已核实依据，发现明显差异才补读。可靠框/视口均无时，米制道路图可按本项目约1:400～1:500、道路两侧几十米量级空白先估计；约175m/幅仅为经验线索。幅长还取决于纸面可用长度，例如350mm在1:500为175m、1:400为140m。
4. 记录范围是`native`、`visual_checked`、`viewport_derived`或`estimated`，附来源和坐标系；代理包围盒可读但内框靠视觉确认时，同时保留这两项事实，不提升为精确内框测量。不因合理日常估计未达到出图测量精度而停住。

内框优先容纳完整标注，跨框是必要时的备选。可接受少量跨入相邻空白，但需检查完整文字可见、相邻组干扰和归属清楚。已知实际视口裁切不同于内框偏好；若发生裁切需调整或按当前任务明确处理。多幅重复显示按同一逻辑对象管理，不重复计工程量。

## 读道路与背景，形成少量区域

先看道路走向、主体与锚点密度，文字优先引到路外。2026-10-15用户明确：本项目已整体灰化的底图文字、引线及其他残留均可压盖，干扰权重很低；不要为了躲灰字、灰线把引线拉长。只有确认仍有效的工程信息或本次新标注需要重点保护。路外拥挤时，Agent可以考虑图内可读空位，记录必要取舍；不把道路主体一律当不可放文字的硬禁区。颜色是项目约定的线索，其他图纸先确认灰化含义，不能仅凭灰色推断所有工程内容失效。

区域可以是道路上侧带、下侧深空白、路口侧方空白等。先用少量矩形/带状范围表达即可，确有需要再用多边形，无需沿所有背景线切碎空间。程序可以核实字框能否容纳、是否碰到指定重要对象，区域取舍仍由Agent决定。

## 锚点、次序与开口

- 点对象锁住真实目标位置；线对象沿所属线、面对象在合法面内选点。面重心不一定在面内，不能直接套用。既有锚点优先保留，变更后复核所属对象。只移动折点/文字不得称为整体移动。
- Agent看相邻锚点相对位置和出口，形成组与排列意图。同向右开口时，右下锚点的标签优先保持右下关系；左开口可作相应类比。这是初始偏好，不是任意斜率/曲路下的无交叉定理，实际引线仍要检查。
- 简单直路同侧优先保持可追踪的次序，密集处用阶梯、平行带或有序扇形；左右开口可分流。同组不必严格等角、等长或等间距，清楚优先于引线最短。
- 平行同开口调用旧修补器时，仍用共同水平基准投影的正确排序，不能直接比较折点x。曲路、混合开口和大面积跨中线目标由Agent结合真实图面安排，不把世界Y正负当道路侧。
- 相邻区域也需一起看，区间分开计算不证明引线互不干扰。固定保护旧组也进入冲突检查。

## Agent与工具交换的最小内容

对小组可直接提供明确A/B/C与原生实际字框；需要工具排位时提供对象ID、目标/锚点约束、优先区域、开口/次序意图及需保护对象。只有遇到问题再补备选区或局部预算，不强制每个标签填写评分表。示例意图：

> 8组使用道路下侧空白，前6组向左阶梯，后2组向右；保留锚点、保护下方说明，优先留本幅；容纳不足时返回具体冲突，由Agent调整。

新建时在数据里先安排，不向成果图批量写任意初值。真实文字尺寸优先用当前原生读取/测量能力；缺少测量时只在适用的临时副本取得尺寸，并如实说明。新内容/字体/上标变化后重新取得实际字框，不沿用旧缓存。

## 预览反馈

个别局部冲突且原因明确，Agent直接换位置、开口、角度或深度，并检查邻组；存在成片冲突、反复挪动或每次制造新问题，返回选区/分组/文字尺寸依据。按图面规模和分布判断，不写死“超过几处”阈值。

灰化残留默认不放入keepouts；确属有效重要信息才选为禁放对象。程序只检查提供的几何与禁放对象，不识别背景重要性、不挑区域、不证明代理内框身份。`review_layout.py`返回软越框提示、几何冲突及未检查项，供Agent取舍；它没有CAD写入能力。实际落图后仍看图，并读回原生位置、字框和关联。内容不隐藏、目标不造假，无法解决的具体组如实交接。
