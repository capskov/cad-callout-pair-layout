# v0.3.0-rc.1 — AutoCAD callout Skill public preview

Preserves v0.3 MCP-first rules and the byte-identical pair_layout.py solver. Includes bilingual Skill instructions, installation/compatibility guidance, 19 generic regressions and a synthetic CLI example. Adds the optional BZYD manual callout-move utility: unchanged Chinese source and English prompt localization, both CP936/GBK without BOM. Owned material is Apache-2.0.

Download cad-callout-pair-layout-v0.3.0-rc.1.zip and SHA256SUMS.txt. Keep the top-level Skill folder and resources together; installation is manual. Solver: Python 3.10+ / Shapely 2.1.2. BZYD alone needs neither Python nor Foundation.

Chinese BZYD has historical AutoCAD 2026 isolated native evidence; English prompts and AutoCAD 2022 remain native-unverified. Static translation/encoding checks do not establish host support. Historical 33-callout save/reopen evidence is limited and used several backends; full Foundation-only styling/layout is not certified. No new native CAD acceptance is claimed for this publication.

Real engineering fixtures, fonts, DWGs, credentials, private paths and legacy COM helpers are excluded. This Skill is not a CAD writer or MCP server. BZYD is a separate human-operated Lisp tool and does not share Foundation governance.
