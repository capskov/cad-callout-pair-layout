# BZYD 人工标注移位工具

[English](README.md)。本目录是可选人工工具，与AI规则／排布器分开。使用它不需要底座、MCP、Python或Shapely。命令是BZYD，不是BZ和YD两个命令，也不是创建新标注命令。

## 安装与人工操作

1. 选中文版callout_move.zh-CN.lsp或英文版callout_move.en.lsp，只加载其中一个。两版定义相同BZYD／bzym:move；后加载的版本会覆盖提示语言。
2. 在AutoCAD用APPLOAD加载选定文件。遵守本机已有可信加载设置，不要求关闭SECURELOAD。首次试用用独立图纸副本，不覆盖原已安装工具。
3. 输入BZYD，选一条普通三顶点LEADER；也可只预选一条后输入命令。不能选MLeader或只选文字，多预选会拒绝。
4. 在“新折点”提示点击目标位置，默认以当前折点为基点。锚点不动，折点、尾段及关联MTEXT移动，斜段接回锚点。
5. 自定义基点时输入B，再点基点和目标位置。Esc／零位移不改对象。工具不提供实时整组拖动预览，只显示标准取点橡皮线。
6. 形成锐角时满足条件才自动换侧，保留文字方向／内容和尾段长度；直角／钝角维持原侧。检查实际结果与其他标注关系。成功操作可一次U／UNDO撤回；如报告恢复无法确认，立即撤销并检查，不连续重试。

只支持同空间、唯一关联MTEXT的普通三点直线LEADER。锁层、共用文字、错类型／关联、非共面、退化目标等会拒绝；不支持尺寸线／MLeader／代理／无关联散线。没有全图自动避让或批量新增标注。

## 版本、编码和证据

两版均为ANSI：本项目明确指CP936／GBK、无BOM。英文内容为ASCII，可按CP936读取；Markdown文档仍UTF-8。中文Lisp与原已验工具逐字节一致；英文仅翻译50个提示／错误文本与注释，控制符号、命令名、DXF处理和算法表达式不变。

原中文版本2026-10-12在AutoCAD2026独立副本完成11组自动换侧／撤销／保存重开检查；不等于人工鼠标体验或整图美观通过。非零DXF213和有钩线对象未单独实测。英文提示版仅完成编码／表达式等价检查，尚无新增CAD实机验收。
